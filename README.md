## Вывод

В ходе выполнения лабораторной работы реализована параллельная версия алгоритма умножения матриц с использованием технологии OpenMP. Экспериментально подтверждено, что увеличение числа потоков приводит к сокращению времени вычислений, однако эффективность масштабирования снижается при превышении оптимального количества потоков для каждого размера матрицы. Наибольший прирост производительности наблюдается при переходе от 1 к 4-8 потокам, дальнейшее увеличение даёт меньший эффект из-за накладных расходов на синхронизацию и ограничений пропускной способности памяти. Для матриц малого размера (200×200) избыточное число потоков может даже снижать производительность. Полученные данные демонстрируют целесообразность подбора оптимального числа потоков в зависимости от вычислительной задачи.
