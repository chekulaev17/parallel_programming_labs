## Вывод

В ходе выполнения лабораторной работы проведено исследование масштабируемости MPI-реализации умножения матриц на кластерной системе. Эксперименты показали, что эффективность параллелизации существенно зависит от размера входных данных. Для матриц размером 200×200 использование 8 процессов даёт ускорение лишь около 3.5× вместо ожидаемых 8×, что объясняется доминированием накладных расходов на межпроцессное взаимодействие над вычислительной нагрузкой. При увеличении размера матрицы до 2000×2000 соотношение «вычисления/коммуникации» становится более благоприятным.

Особое внимание заслуживает результат для матрицы 2000×2000 на 4 процессах: производительность возросла с 1.39 GFLOPS (1 процесс) до 5.42 GFLOPS, что даёт ускорение 3.9×. Это связано с тем, что объём вычислений (16 млрд операций) значительно превышает объём передаваемых данных. Наибольшая производительность (17.71 GFLOPS) зафиксирована на матрице 400×400 с 4 процессами. Полученные результаты характерны для модели распределённой памяти: MPI-программы оправданы при достаточном объёме вычислений, когда время передачи данных становится незначительным по сравнению с временем счёта.
